# Сигнал

Система обратной связи сотрудников: у каждого обращения есть ответственный, срок и проверяемый результат. Повторяющиеся проблемы объединяются, локальный смысловой поиск помогает найти уже решённые вопросы.

**Демо онлайн:** [iwbhappy-modustrade.streamlit.app](https://iwbhappy-modustrade.streamlit.app) — опубликован только интерфейс на демо-данных, без установки. Сервера в облаке нет: ИИ-кнопки отвечают по правилам, поиск похожих — по ключевым словам. Gemini и поиск по смыслу работают в полной версии из репозитория на вашем ключе — см. [Генеративные функции](#генеративные-функции-необязательно).

[Материалы для защиты](docs/pitch.md) · [Концепция](docs/concept.md) · [Архитектура и настройки](docs/architecture.md)

## Что установить

- [Python 3.12+](https://www.python.org/downloads/).
- [uv](https://docs.astral.sh/uv/getting-started/installation/) — устанавливает зависимости Python автоматически.
- [Node.js 22+ с npm](https://nodejs.org/en/download).

Установка uv в Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Установка uv в macOS/Linux:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

После установки откройте новые терминалы. Команды ниже выполняются из корня скачанного репозитория; файлы `.env` для демо не нужны.

## Запуск

### Одной командой (Windows)

Из корня репозитория в PowerShell:

```powershell
.\start.cmd
```

Или двойной клик по `start.cmd`. Скрипт при первом запуске установит зависимости фронтенда, откроет бэкенд и интерфейс в двух окнах и откроет браузер. Остановка — закрыть окна серверов. `.\start.cmd -Mock` — только интерфейс на демо-данных, без бэкенда (http://localhost:5174).

### Вручную

Терминал 1 — бэкенд:

```sh
cd backend
uv run python -m app
```

Терминал 2 — фронтенд:

```sh
cd frontend
npm install
npm run dev
```

`npm install` нужен при первом запуске и после обновления зависимостей. Откройте **http://localhost:5173**. Оба терминала оставьте работающими; остановка — `Ctrl+C`. API и его документация доступны на http://127.0.0.1:8000/docs.

## Первый запуск

Бэкенд применяет миграции и создаёт SQLite-базу `backend/signal.db` с демо-данными. В фоне скачивается модель смыслового поиска (~220 МБ, до минуты) и рассчитываются векторы обращений. Пока модель не готова, работает поиск по ключевым словам; интерфейс подписывает текущий режим. Для поиска внешние AI-сервисы и ключи не нужны.

## Генеративные функции (необязательно)

ИИ-логика работает на сервере и на ваших токенах: ключа в репозитории и в онлайн-демо нет. Ключ можно бесплатно получить в [Google AI Studio](https://aistudio.google.com/apikey).

1. Скопируйте шаблон: `backend/.env.example` → `backend/.env` (или создайте `.env` в корне репозитория).
2. Раскомментируйте строку и впишите ключ: `GEMINI_API_KEY=ваш_ключ` (принимается и `GEMINI_API`).
3. Перезапустите бэкенд (`.\start.cmd` или `uv run python -m app`).

Файлы `.env` исключены из git — не коммитьте ключ и не кладите его в `frontend/.env`: всё, что попадает во фронтенд, видно в браузере.

Кнопки, которые используют Gemini: «Структурировать текст», «Проверить полноту», «Как решали похожее», черновик ответа, «Корневая причина», сводка руководителя и «Сформулировать кратко» в отчёте. Ключ остаётся на сервере. Gemini вызывается только по кнопке; перед отправкой маскируются email, телефоны и номера документов. Повторные запросы кешируются, дневной лимит — `LLM_DAILY_LIMIT=200`. Без ключа, при ошибке или с `LLM_PROVIDER=none` используются правила. В демонстрации отправляйте только синтетические данные. Настройки и ограничения — в [архитектуре](docs/architecture.md#ai-слой).

## Роли для демонстрации

В верхнем переключателе выберите роль и пользователя:

| Кого выбрать | Что посмотреть |
| --- | --- |
| Сотрудник → Сотрудник закупок | Новое обращение, похожие проблемы, свои обращения и подтверждение результата |
| Руководитель → Руководитель закупок | Отчёт за период, входящие и решения по своим назначениям; «От моих сотрудников» — чтение обращений в другие отделы |
| Руководитель → Руководитель направления | Отчёт по компании с печатью/PDF, интерактивная аналитика, повторяющиеся и зарождающиеся проблемы |
| Администратор → Администратор системы | Все обращения целиком, аналитика компании и переназначение; справочники, маршруты и SLA. Решения принимает ответственный |

Пошаговый [сценарий показа на 5 минут](docs/pitch.md#сценарий-показа-5-минут).

В «Отчёте» выберите неделю, месяц или свои даты: группы раскрывают обращения, «Печать / PDF» печатает все группы целиком. «Сформулировать кратко» делает один запрос Gemini на весь отчёт; без него доступны формулировки по правилам. На аналитике графики открывают списки по клику и переключаются в таблицы.

Дизайн переключается кнопкой с палитрой рядом с колокольчиком: «Классический / Material 3». Выбор сохраняется в браузере; для показа можно открыть любой экран с `?design=md3` или `?design=classic` (если параметры уже есть — добавить `&design=…`). По умолчанию используется классический дизайн.

## Без сервера

Из `frontend/` запустите `npm run dev:mock` и откройте http://localhost:5173. Это статическая версия с данными в браузере и поиском по ключевым словам. Подробности и ограничения — в [архитектуре](docs/architecture.md#http-и-статический-mock).

## Streamlit

Опубликованная версия: https://iwbhappy-modustrade.streamlit.app.

Что важно знать об онлайн-версии:
- задеплоен **только интерфейс**: бэкенда, базы и ключей в облаке нет, данные хранятся в браузере каждого посетителя и сбрасываются кнопкой «Сбросить демо-данные»;
- ИИ-кнопки отвечают по правилам, интерфейс это подписывает; Gemini работает только в полной версии на вашем ключе — ключ намеренно не выносится в браузер, иначе его мог бы использовать любой посетитель;
- поиск похожих — по ключевым словам, смысловой поиск требует сервера с локальной моделью;
- бесплатное приложение засыпает после простоя и просыпается около 30 секунд.

Как устроено: приложение `streamlit/streamlit_app.py` показывает готовую сборку `streamlit/build/index.html` (один файл, данные в браузере, поиск по ключевым словам, ИИ-кнопки по правилам). При деплое укажите репозиторий, ветку `main` и файл `streamlit/streamlit_app.py`; зависимости — `streamlit/requirements.txt`. После изменений интерфейса пересоберите: `npm run build:streamlit` из `frontend/` и закоммитьте `streamlit/build/index.html`. Локально: `pip install streamlit`, затем `streamlit run streamlit/streamlit_app.py`.

## Если что-то не так

- **Порт занят:** остановите предыдущий экземпляр приложения (`Ctrl+C` в его терминале) и запустите снова. Бэкенду нужен порт 8000, фронтенду — 5173. Если Vite выбрал другой порт, освободите 5173 и перезапустите его.
- **Нужно вернуть демо:** кнопка «Сбросить демо-данные» внизу боковой панели у администратора или `uv run python -m app.seed --reset` из `backend/`. Это удалит изменения в демо-базе. Та же кнопка сбрасывает данные в mock.
- **Белый экран после обновления:** остановите Vite, удалите папку `frontend/node_modules/.vite`, затем снова выполните `npm run dev` из `frontend/`.
- **Модель не скачалась:** приложение продолжает работать с поиском по ключевым словам. Проверьте соединение с интернетом и перезапустите бэкенд для повторной загрузки модели.
