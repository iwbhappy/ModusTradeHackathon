Дополнительно подготовлено чистое дерево `HEAD` (`b332485`) через `git archive` с незакоммиченными правками очистки, без `node_modules`, `.venv`, базы и модели. В нём выполнены команды README:

- `uv run python -m app` — отказ в доступе к `AppData/Local/uv/cache/.lock`; приложение не запущено.
- `npm install` — `EPERM` при записи в `AppData/Local/npm-cache`; зависимости не установлены.

**Не проверены из чистой копии:** запуск backend, frontend, загрузка модели, `npm run build`, `npm run build:mock` и `uv run pytest`. Успешные проверки рабочего дерева выше не заменяют эту проверку. Настройки проекта для обхода ограничений не добавлялись.

Удаление временной папки после проверки абсолютного пути отклонено автоматической проверкой: `blocked by policy`. Папка осталась: `C:\Users\iwbhappy\AppData\Local\Temp\signal-release-dd0d9c8970744a3dbf1f4de369a51b5e`.

Для закрытия проверки чистой копии требуется повторить команды README вне ограниченного окружения; также остаются подтверждение mock-сборки и удаление указанной временной папки.
