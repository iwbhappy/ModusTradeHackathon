# Этап 8.1 · Читаемость графиков

- `pages/analytics/ChartTooltip.tsx` — общая подсказка для сроков и KPI, без системного `title`. Позиция ограничена карточкой и видимой областью окна, у правого края подсказка сдвигается влево. Пересчёт при прокрутке/изменении размеров, закрытие по Escape.
- `pages/analytics/DeadlineHealth.tsx` — образцы заливки 12×12 px с теми же классами цветов, что у сегментов; подпись «Скоро срок (≤ 3 раб. дня)». Легенда связана с подписью оси. Наведение и фокус показывают подразделение, состояние, число обращений и приглашение открыть детализацию.
- `pages/analytics/ProblemTreemap.tsx` — раскладка учитывает фактические размеры карты и метрики загруженного шрифта. Плитки меньше 120×64 px либо без места для целого названия и числа вынесены в «Небольшие проблемы»: тренд, название, чел.-ч/мес и число обращений; строки открывают кластер. Сборная нейтральная плитка «Ещё N проблем» показана только при достаточном месте, переводит фокус к списку и подсвечивает его. Дополнительная подпись обычной плитки выводится только целиком; пересчёт при изменении размера и загрузке шрифтов.
- `pages/analytics/KpiSparkline.tsx`, `Kpis.tsx` — подсказки недели из `fromDate/toDate`, значения с единицами, увеличение выбранной точки и вертикальная направляющая. Последняя точка и значение видны постоянно; текущая неделя подписана как незавершённая. Под графиком — диапазон дат, для текущей недели до сегодняшнего дня. SVG подстраивается к ширине карточки, сохраняя текст 12 px. Клик/Enter/Space открывают ту же неделю, что и таблица.
- `pages/UsersPage.tsx` — пояснение об оргструктуре и пилотной синхронизации с Битрикс24. Указаны только существующие действия: отметка отпуска и замещения в правилах назначения; назначения ролей на этом экране не обещаются.
- `visual.css` — оформление подсказок, образцов, точек/значений и компактного списка, адаптивность строк и выделение списка при переходе из сборной плитки. Логика графиков общая для HTTP и mock.

Пути выше относительно `frontend/src/`. Бэкенд, API, зависимости и другие экраны не менялись. Новые тесты, smoke-скрипты и харнессы не создавались; Gemini не вызывался, коммитов нет.
