## Как запустить и проверить
- Бэкенд: `cd backend && uv run python -m app` (миграции и сид применяются сами). Первый запуск скачивает модель эмбеддингов (~220 МБ) в `backend/models/`.
- Фронтенд: `cd frontend && npm run dev`. Статическое демо без сервера: `VITE_API_MODE=mock npm run build`.
- Сброс демо: `cd backend && uv run python -m app.seed --reset` или кнопка у администратора.
- Проверки: `cd backend && uv run pytest` (15 тестов), `cd frontend && npm run build`.
- Сценарий демо по шагам: `README.md`, раздел «Демо по шагам» (10 шагов).
- Превью в приложении Claude: `.claude/launch.json` (`backend` на 8000, `frontend` на 5173).

## Что проверено руками
- Через API: создание, маршрутизация, запрещённые переходы (409), обязательные тексты, ответ на уточнение, 403 на чужое обращение и для администратора, аналитика по области доступа, уведомления, сброс.
- В браузере: подача обращения, панель похожих (открытые и «уже рассмотрено»), смена статуса руководителем, аналитика (в том числе сводка по компании и зарождающиеся проблемы), защищённый журнал и его нарушение.
- Скриптом: смысловой поиск на 8 запросах, автопривязка к кластеру, оформление кластера (права 403/201), целостность журнала на всех 63 обращениях.

## Известные ограничения и замечания
- **LLM нет.** Ключей API в окружении нет, поэтому структуратор и черновики ответов работают на правилах и дают шаблонный текст. Это самое слабое место демо: если появится ключ или локальная LLM, первым делом сделать `LLMProvider` (интерфейс `AIProvider` уже готов).
- Модель эмбеддингов (MiniLM) слабо справляется с очень короткими разговорными фразами («дважды вбиваю одно и то же») — близость ниже порога 0,5. Пороги и модель задаются настройками.
- Матрица трения в основном диагональная: большинство демо-проблем относится к собственному подразделению автора. Для более яркой картины стоит поправить `targetDepartment` у части обращений в `data/seed.json`.
- `JWT_SECRET` по умолчанию случайный при каждом запуске: после перезапуска бэкенда фронтенд перелогинивается сам. `AUDIT_KEY` по умолчанию демо-константа.
- После больших правок dev-сервер Vite иногда ломается на автообновлении: остановить, удалить `frontend/node_modules/.vite`, запустить снова.
