# ТЗ для Codex · Этап 7.1 · Две визуальные правки по итогам приёмки

Этап 7 принят: отчёт за период, воронка, здоровье сроков, динамика и новая палитра выглядят хорошо. Нужно поправить два места.

## 1. Карта повторяющихся проблем (treemap) — подписи в маленьких плитках
`frontend/src/pages/analytics/` — плитка треемапа. Сейчас в маленьких плитках название и число обрезаются, текст наезжает на верхнюю границу соседней плитки, а в самой узкой плитке видно только «5» с обрезанной подписью.

Правильно:
- плитка показывает подпись только если помещается: при ширине < 120 px или высоте < 64 px — только число часов; при ширине < 56 px или высоте < 36 px — без подписи вообще;
- полная информация всегда доступна в подсказке при наведении и в режиме «Таблица»;
- текст не выходит за пределы плитки (`overflow: hidden`, многоточие для названия в 2 строки максимум);
- между плитками — зазор 2 px цвета фона карточки.

## 2. Дельта KPI, когда за прошлый период данных нет
На «Аналитике» за 90 дней предыдущий период пустой (демо-данные покрывают ~10 недель), и карточки показывают «↑ +63 новое значение · ранее 0». Это выглядит как ошибка. Правильно: если в предыдущем периоде значение 0 и данных нет, вместо стрелки и дельты писать приглушённым текстом «нет данных за прошлый период». Для отчёта за период — та же логика.

## Ограничения
- Тестов не писать, Gemini не вызывать, больше ничего не менять, не коммитить.
